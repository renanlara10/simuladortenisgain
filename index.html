☁️ Sincronizar entre dispositivos (via GitHub)

Usa um Gist privado do GitHub (um arquivo de texto na nuvem) pra guardar seus dados. Passo único: vá em github.com/settings/tokens → "Generate new token" → "Generate new token (classic)" → marque só a permissão gist → gere e copie o token. Cole abaixo, clique em "Criar Gist" uma vez (só no primeiro dispositivo), e nos outros dispositivos cole o mesmo token + o ID do Gist gerado, e clique em "Baixar".

Importar novo torneio

Cole uma linha por partida, na ordem cronológica (mais antiga primeiro). Campos separados por TAB, ponto e vírgula ou vírgula:
Data [horário opcional]; Fase; Jogador A; Odd A; Jogador B; Odd B; Vencedor (A, B ou o nome do vencedor)
Inclua o horário junto à data (ex: "05.01 09:30") sempre que possível — isso é essencial pra ordenar corretamente jogos de torneios diferentes que acontecem no mesmo dia, ao compilar o histórico geral.
